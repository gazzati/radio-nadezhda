# Радио «Надежда»

Первая версия: статический адаптивный сайт с плеером. Без сборки, внешних библиотек и регистрации слушателей.

## Подключение эфира

В `dist/config.js` укажите публичный HTTPS-адрес **самого аудиопотока** в `streamUrl`, например `https://radio.example.org/listen/nadezhda/radio.mp3`. Это пример, а не существующая станция. MP3-поток Icecast/RadioBOSS подходит; HTML-страница сервера или адрес панели управления не подходят. HLS в этой версии специально не реализован.

Пока адрес пустой, страница показывает «Скоро в эфире», а элементы управления отключены. Чужие записи и поток МОЛОКО не используются.

Воспроизведение начинается только по нажатию пользователя. Плеер показывает подключение, воспроизведение и ошибку, позволяет отменить подключение, остановить эфир и изменить громкость. Остановка освобождает сетевое соединение; повторное включение присоединяется к текущему эфиру. Через 15 секунд ожидания предлагается повторная попытка. На iOS громкость может управляться только системными кнопками устройства.

При наличии поддержки браузера доступно управление через Media Session. Работу в фоне необходимо проверить на целевых iPhone/Android с реальным потоком. Название текущего трека потребует отдельного адреса API радиосервера; сейчас отображается название станции.

## Локальный просмотр

Из каталога `site`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4173`. Весь публичный сайт находится в `dist/` и может размещаться на обычном статическом хостинге. Панель управления радио, сам радиосервер и каталог подкастов в эту версию не входят.
